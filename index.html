Publications

DRIP: Self-Improving Robot State Estimation In-the-Wild via Dense Robot-Fitting In the Loop

Kim Ohn, Kim Youwang, Junuk Cha, Tae-Hyun Oh

IEEE Robotics and Automation Letters (RA-L), accepted 2026

Project arXiv · Soon
TL;DR

Learn robot pose and joint angles from real images without 3D state labels. Dense robot-fitting refines predictions during training and feeds them back as pseudo-labels, improving the network while keeping single-shot inference.

UFO: Uncertainty-aware LiDAR-image Fusion for Off-road Semantic Terrain Map Estimation

Ohn Kim*, Junwon Seo*, Seongyong Ahn

IEEE Intelligent Vehicles Symposium (IV), 2024 (* equal contribution)

Project arXiv PDF (extended version)
TL;DR

Fuse a single LiDAR scan with an RGB image to estimate a dense off-road terrain map. Image-guided pseudo-labels reduce the need for manual 3D annotation, and uncertainty-aware training reduces the influence of unreliable labels.

Design and source code from Jon Barron's website.
